# Menu HR — Karyawan, Rekrutmen & Psikotes, Payroll

**Status:** disetujui user 2026-10-10 ("ikut usulan kamu semua, gas"), mockup di chat. Dikerjakan bertahap:
**Fase 1 Karyawan → Fase 2 Rekrutmen + Psikotes → Fase 3 Payroll.**

## Tujuan

Satu menu **HR** di sidebar (grup baru, dekat Produktivitas) untuk mengelola orang di SKINKU: mencari kandidat,
menyaring dengan psikotes, menerima jadi karyawan (data + onboarding), lalu menggaji tiap bulan.

## Keputusan

| Topik | Keputusan |
|---|---|
| Urutan | Karyawan dulu (dasar payroll), lalu Rekrutmen + Psikotes, terakhir Payroll |
| Tes | Kepribadian **16 tipe** (label bukan "MBTI" — merek dagang, kuesioner resmi berlisensi), **DISC** (gaya kerja), **logika & hitung**. Soal disusun sendiri; hasil = info pendukung, bukan satu-satunya dasar keputusan |
| PPh 21 | Otomatis tarif efektif rata-rata (TER, PP 58/2023) + bisa dikoreksi manual per baris |
| Angka gaji | Hanya super admin, kecuali diberi izin khusus (pola `view_hpp`) |
| Slip gaji karyawan lewat portal | Ditunda (bukan cakupan awal) |
| Data pribadi | UU PDP: izin terpisah, kolom sensitif cast `encrypted` + `$hidden`, dokumen di disk **privat** (bukan `public`), semua perubahan di Audit Log tanpa nilai sensitif, tidak pernah dikirim ke Asisten AI |
| Mitra | Semua route HR di balik middleware `internal` (mitra diblok keras, apa pun matriks izin) |
| Dependency | Nol paket baru: slip gaji = halaman cetak (browser → Simpan PDF), seperti cetak PO |

## Izin (`App\Support\Permissions`)

| Key | Arti | Default |
|---|---|---|
| `hr.view` | Lihat data karyawan non-sensitif (nama, jabatan, divisi, status, tanggal, progres onboarding) | `admin` |
| `hr.manage` | Kelola karyawan & onboarding; lihat/ubah data identitas (NIK, NPWP, rekening, alamat, BPJS, kontak darurat) & dokumen | — (super admin) |
| `hr.recruit` (Fase 2) | Kelola lowongan, kandidat, psikotes | — |
| `payroll.view` / `payroll.manage` (Fase 3) | Lihat / jalankan & kunci payroll (angka gaji) | — |

## Fase 1 — Karyawan (database + onboarding)

**Tabel `employees`** (migrasi additive): `kode` (KRY-0001, otomatis), `user_id` (opsional, akun portal staf),
`name`, `position`, `department`, `employment_type` (tetap / kontrak / percobaan / magang / harian),
`status` (aktif / keluar), `join_date`, `probation_end`, `contract_end`, `resign_date`, `resign_reason`,
`phone`, `email`, `birth_date`, `gender`, `ptkp_status` (TK/0…K/3, dipakai PPh 21 Fase 3), `onboarding` (JSON
`{item: {selesai, oleh}}`), `notes`, `created_by`, soft delete.
**Terenkripsi + `$hidden`:** `nik`, `npwp`, `address`, `bank_name`, `bank_account`, `bank_account_name`,
`bpjs_kesehatan`, `bpjs_ketenagakerjaan`, `emergency_contact`.

**Checklist onboarding** (tetap di kode): KTP & KK, NPWP, Rekening gaji, BPJS Kesehatan & Ketenagakerjaan, Kontrak
ditandatangani. Tiap item: centang selesai (siapa & kapan) + unggah dokumen (`ImageService::attach` ke disk privat,
koleksi `hr_{item}`), diunduh lewat route berizin `hr.manage` (bukan URL publik).

**Halaman:**
- Daftar karyawan: kartu ringkas (aktif, masa percobaan berakhir ≤30 hari, kontrak berakhir ≤30 hari, onboarding
  belum lengkap), saring status/divisi/cari, kolom kode, nama, jabatan, divisi, status kerja, mulai, progres onboarding.
- Detail: profil, tanggal penting + pengingat, checklist onboarding + dokumen; data identitas hanya untuk `hr.manage`
  (selain itu "disembunyikan").
- Form tambah/ubah (`hr.manage`), termasuk status keluar + tanggal & alasan.

**Audit:** `create_employee`, `update_employee` (nilai non-sensitif sebelum → sesudah; kolom sensitif hanya
namanya), `employee_onboarding` (centang/batal), `upload_employee_document`, `delete_employee_document`,
`view_employee_document`.

## Fase 2 — Rekrutmen + Psikotes (ringkas)

- `job_openings` (judul, divisi, status buka/tutup, deskripsi) · `candidates` (nama, kontak, lowongan, tahap
  lamar → psikotes → interview → diterima / ditolak, CV di disk privat, jadwal interview, catatan).
- Sesi tes: token unik, link tanpa login (berlaku 7 hari, sekali pakai, dibatasi laju), batas waktu per tes, jawaban
  & skor JSON. Skor otomatis: 16 tipe (4 dimensi), DISC (most/least), logika (benar/salah).
- "Jadikan karyawan" dari kandidat diterima → form karyawan terisi otomatis (Fase 1).

## Fase 3 — Payroll (ringkas)

- Komponen per karyawan: gaji pokok, tunjangan tetap, ikut BPJS (Kesehatan, JHT, JP, JKK, JKM; tarif & batas upah
  di setelan), status PTKP.
- Run bulanan: draf (tambah lembur/bonus/kasbon, koreksi PPh 21 manual) → kunci (angka beku) → slip cetak.
- PPh 21 TER bulanan (kategori A/B/C dari PTKP), Desember = hitung ulang tahunan (tarif Pasal 17).
- Saat dikunci: jurnal ke Akuntansi (beban gaji & BPJS bagian kantor, utang gaji, utang PPh 21/BPJS).
